# Roadhunt OpenStreetMap snapshot

This directory contains the generated SQL snapshot used by the local Roadhunt
database. It was fetched through the Overpass API on 2026-08-20 and contains
45,582 grouped, named streets across all twelve launch cities.

- Source: OpenStreetMap contributors
- License: ODbL
- Source timestamp: `2026-08-20T17:59:04.000Z`
- Smallest city/difficulty pool: 44 streets
- Synthetic targets in the active database: 0

The files are generated by `scripts/import-osm.ts`. A normal `supabase stop`
and `supabase start` preserves the imported data. `npm run db:reset` recreates
the deterministic synthetic test seed; after such an intentional reset,
regenerate or re-import this snapshot before playing with real streets.

Generate a fresh snapshot:

```sh
npm run osm:import -- --all --fetch --format sql --output ./data/osm
```

The generated SQL is idempotent for matching street names. Import every city
file with `psql` against the target database, then remove rows whose
`source->>'kind'` is `synthetic-demo` once all twelve imports succeeded.
